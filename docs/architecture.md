# 架构

```text
环境变量 + 私人配置
        ↓
只读 Wolai MCP → 每页完整块扫描 → 稳定正文指纹与变更计划
                                     ↓ --apply
                            Notion 原生块/媒体写入
                                     ↓
                     来源、父级、正文覆盖、媒体读回检查
                                     ↓
                         私人状态 + 目录移动恢复日志
```

CLI 在读取任何来源前验证非空根列表，并将每次扫描/续传限定在这些根及其后代。数据目录的 `configBinding` 将来源列表和 Notion 根绑定；不存在“默认同步全部账户”的入口。

`source-tree` 对每页完整读取，不依赖父版本聚合；正文指纹忽略临时下载签名，不忽略正文修改。`tree-sync` 按深度先父后子，在实际读取目标子块后补齐第三层及更深原生块。

`notion-catalog` 仅认领授权根内的镜像。来源标识防重复，旧页面认领还需要路径、正文及媒体相符；多个候选不强行选择。每次写入经独立来源覆盖/媒体检查与读回后才推进成功版本。

`page-order` 使用受管页面移动保留 ID 与正文，不以 Markdown 往返排序；本地日志支持中断恢复。正文操作、目录检查与移动尝试共用批量额度。

`verify-workspace` 只读远端，复核全部页面、来源覆盖、媒体数量与目录，并抽核至多三个媒体页的字节。整页 ZIP 会单独验证附件，不能冒充内联正文。所有报告与原文缓存都只存放在私人数据目录。

互斥锁只保护同一机器、同一数据目录。没有跨主机分布式事务或远程写入租约；多个设备不能同时写同一个镜像树。
